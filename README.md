# Tugas-Games-2D
Kesimpulan:  Dijkstra dan A* menghasilkan jalur optimal dengan biaya sama, namun A* lebih efisien karena mengeksplorasi node lebih sedikit berkat heuristik Manhattan yang admissible dan konsisten. A* unggul untuk pencarian titik-ke-titik, sedangkan Dijkstra cocok untuk eksplorasi menyeluruh.
